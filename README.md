# Student Performance Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a student performance dataset to identify patterns, relationships, and trends.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Dataset exploration
- Statistical summary
- Missing value checking
- Duplicate checking
- Subject-wise analysis
- Attendance analysis
- Correlation analysis
- Distribution analysis
- Outlier analysis

## Visualizations

- Bar charts
- Histograms
- Boxplots
- Scatter plots
- Correlation heatmap

## Key Insights

The analysis helps understand student attendance, subject performance, mark distributions, and relationships between different variables.

## Conclusion

This project demonstrates how Exploratory Data Analysis can be used to understand a dataset, discover patterns, and generate meaningful insights using Python.
